# Set up Agentic Users

## 1. Set up an AI teammate

Follow the **AI teammate** path in [Connect an existing agent to Agent 365](https://learn.microsoft.com/microsoft-agent-365/developer/get-started). To perform the setup directly with the CLI instead, see [Set up an agent blueprint](https://learn.microsoft.com/microsoft-agent-365/developer/registration).

## 2. Configure Teams SDK

Configure Teams SDK with the blueprint identity. It uses the same authentication settings as a standard Teams app, and the blueprint ID is the application (client) ID.

| Agent 365 value      | App authentication setting                                                       |
| -------------------- | -------------------------------------------------------------------------------- |
| Blueprint ID         | Application (client) ID (`CLIENT_ID`)                                            |
| Blueprint credential | Client secret, user-assigned managed identity, or federated identity credentials |
| Tenant ID            | Tenant ID (`TENANT_ID`)                                                          |

Configure these values as described in <LangLink to="essentials/app-authentication/">App Authentication</LangLink>.

## 3. Deploy and register the messaging endpoint

Deploy your Teams SDK app to a publicly accessible host, then [register its messaging endpoint](https://learn.microsoft.com/microsoft-agent-365/developer/agent-messaging-endpoint), typically `https://<host>/api/messages`.

## 4. Publish and create an instance

[Publish the agent](https://learn.microsoft.com/microsoft-agent-365/developer/publish) to the Microsoft 365 admin center, then [configure the blueprint and create an agent instance](https://learn.microsoft.com/microsoft-agent-365/developer/create-instance).

After the instance is approved, its Agentic User can communicate through the deployed Teams SDK app.
